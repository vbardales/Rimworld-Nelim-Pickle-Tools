## What the runs taught, beyond the steps

- **Parentheses in Cucumber Expression are optional text.** `at ({int}, {int})` is optional group containing parameters, illegal, and Pickle builds whole step table before running anything: one bad pattern of
  87 played zero scenarios of nineteen, reported `infrastructure-error`. Escape them, `\(` and `\)`, written
  `\\(` and `\\)` in C# literal. Failure `PickleTools`' own `Check-Steps` was written against.
- **Keyword is decoration.** `Given` setter and `Then` assertion spelled identically are one ambiguous
  step, not two. Three pairs got in before anything compiled them.
- **Game ticks between two steps.** Mod's own pass runs on those ticks, so scenario that switches bench on then lowers cap finds allowance already spent. Order setup so configuration precedes
  activation.
- **Fixture is played colony.** `test-colony` has `ComplexClothing` researched, so scenario about recipe
  unlocked later had nothing new to show; research list readable offline in `Pickle/Fixtures/test-colony.rws`
  (`<progress>` keys against values), and `Pemmican` is zero there.
- **Suite's own checker** is `BillAutopilot/Tests/Pickle/Check-Steps.ps1`. File `PickleTools`' tool
  checkers grew out of, since taken their ambiguity half back: Pickle's vocabulary read with Mono.Cecil
  from assemblies not documentation, compared against every other step source in collection.
