# Pickle 6.6.3 to 6.7.5: what changes for Pickle Tools (offline analysis, 2026-11-19, nothing played)

Source: git diff v6.6.3 v6.7.5 of RimWorks/Rimworld-Pickle (26 commits, 74 files, 2026-10-08 to 2026-11-17). Not built, not run.

## Changes that touch us
1. **Main-thread context (b0b00d4, 2026-10-16).** PickleDriver now installs a MainThreadSyncContext: every await continuation resumes on the main thread, also after a non-main await. Our local "OnMainThread" guards (StageDecor DecorSteps.cs:1680, ColonistRace LookSteps.OnMainThread) become redundant but stay harmless. Only one file of ours uses Task.Run / ConfigureAwait / Thread.
2. **Camera.** Pickle now lowers CameraMapConfig.sizeRange.min to 3 (CloseSize 12 to 3, FarSize 50) and adds `I zoom the camera to {float} cells` and `the camera is zoomed to {float} cells`. Our CameraZoom README and probe state the game stops the zoom at root size 11 (Pickle 6.6.3, ticket 9e60): that statement is false on 6.7.5, and CameraZoomSteps.cs:24-32 (own sizeRange handling) overlaps. To replay: the CameraZoom probe on 6.7.5 and the close-up frames (VaC lips).
3. **New unprefixed steps** in Pickle.Vanilla: `I set the terrain from (x, z) to (x, z) to {string}`, `the terrain at (x, z) is {string}`. Ours carry the "Nelim's Pickle Tools:" prefix, so no Ambiguous step expected, to be proved by Check-Steps against 6.7.5. StageDecor's floor steps could use them, not required.
4. **Window steps** use a null-safe OpenWindows(); `a warning from mod` step now waits (AssertEventually).
5. **1.7.** Pickle builds 1.5/1.6/1.7 (net10 for 1.7, Pickle.Ref per GameTfm); 1.7 reads frames on the main thread (leak). The Ref NuGet package referenced by our 26 csproj is "4.*" (floating), one pins 4.8.3: a rebuild resolves whatever the feed holds, not 6.7.5 unless the feed carries it. Unverified which Ref version the feed gives.
6. Runner UI, HTTP server, gherkin writer, fixtures: no step API change seen.
