# Fieldwork Companions

Repository `FieldworkCompanions`, folder `Tests/Pickle/Source/`, built by
`dotnet build Tests/Pickle/Source/FieldworkCompanions.PickleSteps.csproj -c Release` into
`Tests/Pickle/Mod/Pickle/Assemblies/FieldworkCompanions.PickleSteps.dll` (committed, staging copies folder verbatim).
Every phrase carries mod name (`Fieldwork Companions: ...`, `the Fieldwork Companions ...`), same reason as above.
Written 2026-09-21. **The *Played* notes below come from one partial WSL run** (English, 19 of 32 scenarios, then game ended
without writing report, cause unknown): what it reached passed or failed as stated, rest not run. Fix made after
that run marked "not replayed".

probably wrong: Pickle records button under its *label*, so fitting step is `KeyedClick/`'s `I click button keyed {string}`,
and staging it means pass that is not the bare one. Not yet changed.
